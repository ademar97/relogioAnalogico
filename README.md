# 🕒 Relógio Analógico

Aplicação web simples e funcional de um **Relógio Analógico em tempo real**, desenvolvida com tecnologias fundamentais do ecossistema Web (HTML, CSS e JavaScript).

---

### 🚀 Funcionalidades

* **Tempo Real:** Sincronização dos ponteiros de horas, minutos e segundos utilizando o horário local da máquina.
* **Interface Dinâmica:** Animação fluida dos ponteiros orientada por manipulação do DOM e CSS.
* **Design Responsivo:** Adaptável a diferentes tamanhos de tela.

---

